# InjectorWIZARD

InjectorWIZARD is a MATLAB-based tool for designing rocket engine injectors. It supports all major injector types including coaxial swirl and jet configurations, pintle variants, and impinging designs. It was developed to streamline early-stage injector architecture selection and accelerate design iteration.

## Core Features and Architecture

1. Coaxial Swirl
2. Coaxial Shear
3. Jet Swirl
4. Swirl Jet
5. Variable Pintle
6. Fixed Pintle
7. Doublet Impinging
8. Triplet Impinging
9. Gas Jet

## Project Scope

Preliminary sizing tool designed to rapidly iterate injector architecture. Injector design should always be supported by cold flow testing.

## Installation and Documentation

To get started, navigate to the releases section in the repository where you will find:

1. **InjectorWIZARD_Installer.exe**: A standalone Windows installer executable. Runs independently without requiring a full MATLAB local license installation (utilizes the free MATLAB Runtime environment R2026a).

2. **InjectorWIZARD.pdf**: A document outlining all underlying analytical models used inside the application backend.
